# Chat V0

This is the V0 permanent-launcher setup.

## Files

- `launcher.html` — the one-file launcher you can keep/distribute.
- `chat.html` — the actual Chat page.
- `css/style.css` — Chat styling.
- `js/` — Chat JavaScript split into logical files.

The Chat HTML currently loads the CSS and JavaScript from this GitHub repository through jsDelivr:

`https://cdn.jsdelivr.net/gh/sashabolton0-ux/chat@main/`

## GitHub upload

Upload the contents of this folder to the root of the `chat` repository.

Do not upload the ZIP itself.

Keep the folder structure exactly as shown.
